MODULAR STRATEGY RUNTIME

Strategies plug into a platform, not a pile of scripts.

The Monaco trading bot already supports a strategy library, typed Studio parameters, isolated instances, lifecycle controls, persistent datasets and hot discovery of trusted modules.

01 / MODULE

Python strategy + definition

A strategy exposes its class, market requirements and validated parameters without requiring frontend changes for every new module.

02 / INSTANCE

Run it in isolation

Each launched strategy receives its own identity, configuration, dataset path and runtime state.

03 / LIFECYCLE

Start, pause, resume, stop

Operator controls make state explicit, including open-order cleanup and conservative behaviour across restarts.

AI-ASSISTED EVOLUTION

Let AI propose. Let evidence compete.

The integrated assistant can read strategy code and measured results, run comparable backtests and create new settings or code drafts. It cannot silently change a running strategy.

Important design boundary

Metanyx's current implementation is AI-assisted, not self-authorising. The assistant can create drafts and run tests; installation and launch remain explicit human actions.

PINNED CODE + LOCKED SETTINGS

An evolving system still needs immutable history.

When a strategy launches, its settings lock and its strategy code is content-addressed and snapshotted. Later code updates do not rewrite the historical run.

01 / SNAPSHOT

Content-addressed source

Strategy modules and imported dependencies are copied into a code snapshot with SHA-256 hashes.

02 / PROVENANCE

Bot commit + runtime

Each run records platform context so measured results can be tied to a specific implementation.

03 / PORTABILITY

Export and recreate

Run exports can bundle settings, code snapshot, manifest and performance history for review or recreation.

EVOLUTION WITHOUT CHAOS

New logic earns promotion.

AI-generated strategies should advance through evidence gates rather than directly into capital.

01 / VALIDATE

Syntax and parameter checks

Draft modules can be loaded in isolation and validated before entering the installed strategy library.

02 / BACKTEST

Compare across data sources

Monaco, Binance and Hyperliquid histories can challenge changes across periods and market paths.

03 / SHADOW → LIVE

Escalate deliberately

Research can move from replay to paper or shadow operation and then to gated live execution.
