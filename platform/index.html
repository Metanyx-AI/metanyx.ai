STRATEGY LIFECYCLE

Build, test and operate without losing provenance.

A strategy is more than an entry signal. Metanyx treats configuration, source code, runtime state and results as one traceable lifecycle.

01 / DISCOVER

Typed strategy modules

Strategy modules expose validated parameters and supported run modes so operators can understand what will launch before capital is involved.

02 / LAUNCH

Isolated runs

Paper, shadow and gated live paths keep strategy state separated while preserving the same observable lifecycle.

03 / INSPECT

Operational diagnostics

Signals, queue pressure, errors, decisions and runtime health remain visible from the operator interface.

DATA + REPLAY

Turn live markets into research memory.

Market data is normalized for the fast path, then persisted off that path for analysis. Replay sends recorded events through live-style state so strategy behavior can be compared under repeatable conditions.

01 / CAPTURE

Books, trades and events

Completed candles, trades, BBO observations and order events create an attributable record of what a strategy could see.

02 / REPLAY

Exchange-aware simulation

Recorded books and trades drive simulated acknowledgements, cancels and confirmed fills rather than simplified candle-only assumptions.

03 / EXPORT

Portable run evidence

Locked settings, code hashes and exportable run bundles connect a result to the exact logic and inputs that produced it.

EXECUTION SAFETY

Treat uncertain exchange state as a risk.

Execution controls are designed around incomplete information, reconnects and asynchronous venue responses—not the assumption that every request succeeded.

01 / ACCOUNT

Confirmed-fill accounting

Positions change from confirmed fills rather than optimistic order requests, keeping strategy state tied to venue evidence.

02 / RECONCILE

Reconnect deliberately

Open orders and positions are reconciled after transport interruptions before normal operation resumes.

03 / FAIL CLOSED

Bound the downside

Stale feeds, reference disagreement, position limits and emergency controls can reduce or stop risk when confidence falls.
