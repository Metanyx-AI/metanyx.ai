REPRODUCIBLE RUNS

Know exactly what produced a result.

A backtest is useful only when its assumptions and implementation can be recovered. Metanyx binds settings and strategy source to each run.

01 / LOCK

Immutable settings

Run parameters lock at first start so later edits cannot silently rewrite the meaning of an existing result.

02 / PIN

Content-addressed code

Strategy source is hashed and snapshotted, connecting performance and diagnostics to a specific implementation.

03 / SHARE

Exportable evidence

Run bundles make settings, identifiers and results portable for review and comparison.

MARKET REPLAY

Replay the market, not a cartoon of it.

Order-book strategies depend on event sequence, queue conditions and acknowledgements. Replay preserves those mechanics more faithfully than candle-only evaluation.

01 / EVENTS

Recorded market state

Books, trades, candles and BBO observations are persisted as research inputs without blocking trading I/O.

02 / LIFECYCLE

Live-style order flow

Simulated acknowledgements, cancels and confirmed fills exercise the same state transitions that strategies face live.

03 / COMPARE

Repeatable scenarios

Comparable inputs make parameter changes and strategy drafts easier to evaluate without conflating them with a different market sample.

AI-ASSISTED RESEARCH

Use models to propose; use evidence to decide.

An integrated assistant can examine strategy code and results, run comparable tests and prepare drafts. Humans retain the review boundary before installation or launch.

01 / READ

Grounded context

The assistant works from strategy source, declared parameters and measured results rather than an isolated prompt.

02 / TEST

Comparable evaluation

Candidate settings or logic can be exercised against the same replay windows and diagnostics.

03 / REVIEW

Human approval

Generated changes remain drafts until a person reviews and explicitly promotes them into the strategy lifecycle.
